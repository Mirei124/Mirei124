# 日语声调

0型: 我哥 うえ

1型: 哥哥 あか

2型: 我哥哥 あおい

3型: 美滋滋的 なつやすみ

0型没有高-低

1型高-低出现在第1个字

2型高-低出现在第2个字

3型高-低出现在第3个字

1. 日语中没有高-低-高的单词
2. 第1，2个音不同音调
3. うし　０型 やま　2型

## 长音

1. あ段假名+あ
   1. おかあさん　妈妈
   2. おばあさん　奶奶
   3. さあさあ　来吧
   4. まあまあ　行
   5. おばさん　阿姨
2. い段假名+い
   1. おにいさん 哥哥
   2. おじいさん 爷爷
   3. ちいさい 小的
   4. おじだん 叔叔
3. う段＋う
   1. つうやく1
   2. すうがく0　数学
   3. ゆうき1　勇気
   4. ゆうじん０ 友人
4. え段假名＋え、い
   1. おねえさん　姐姐
   2. せんせい　先生
   3. へいわ０　平和
   4. ねえねえ１
